# 服务脚本使用说明

> 本文描述仓库根目录**真实存在**的 3 个 Windows 脚本 + 2 个 Linux 脚本。
> 维护说明：脚本增删/改名时同步更新本文与 README。

## 脚本一览

| 脚本 | 平台 | 作用 |
|------|------|------|
| `install-complete.bat` | Windows | 一键安装：检测 Python/Node、建后端 venv、装后端+前端依赖、验证启动 |
| `start-services.bat` | Windows | 启动服务（可选开发模式[热重载] / 生产模式[build+preview]），首次运行自动建 venv 装依赖 |
| `stop-services.bat` | Windows | 停止服务（**按端口 8002/5173 精确定位** PID，不触碰机器上其他 Python/Node 进程） |
| `start-services.sh` | Linux/macOS | 开发模式启动（nohup 后台，日志写 `logs/`），首次自动建 venv + node_modules |
| `stop-services.sh` | Linux/macOS | 按端口精确停止（lsof 优先，ss/fuser 兜底；先 TERM 后 KILL） |

## Windows 使用

### 首次安装
```cmd
install-complete.bat
```
自动完成：Python/Node 检测 → 后端 venv 创建 → 依赖安装（`backend/requirements-windows.txt`）→ 前端 `npm install` → 核心依赖与 `/mcp` 挂载验证。

### 日常启动
双击 `start-services.bat`，选模式：
- **[1] 开发模式**：后端 `--reload` + 前端 `npm run dev`（改代码即生效）
- **[2] 生产模式**：后端不 reload + 前端 `npm run build` 后 `npm run preview`

脚本会在新窗口分别拉起后端（:8002）与前端（:5173），并自动打开浏览器。

### 停止
双击 `stop-services.bat`。它只杀**占用 8002 / 5173 端口**的进程：
```
netstat -ano | findstr ":8002" | findstr "LISTENING"  →  取 PID  →  taskkill /pid <PID> /f
```
> 不会误杀 IDE、其他 Python/Node 程序。停止后可用 `netstat -ano | findstr ":8002 :5173"` 确认端口释放。

## Linux/macOS 使用

```bash
./start-services.sh    # 启动（后台运行，日志 logs/backend.log、logs/frontend.log）
./stop-services.sh     # 停止（按端口精确定位）
```
> 首次运行会自动 `python -m venv venv` 并安装依赖、`npm install`。依赖清单与 Windows 相同（`backend/requirements-windows.txt`，内容跨平台通用）。

## 故障排除

### 端口被占用
```bash
# Windows
netstat -ano | findstr ":8002"
taskkill /pid <PID> /f
# Linux
lsof -i :8002
kill -9 <PID>
```
或直接运行 `stop-services.*` 精确释放。

### 服务启动失败
1. 看日志：Windows 看 start-services 弹出的窗口；Linux 看 `logs/backend.log` / `logs/frontend.log`。
2. 确认 Python 3.8+ / Node 16+ 在 PATH（或 WorkBuddy 受管运行时，脚本会自动回退探测）。
3. 确认 `backend/venv` 完整：损坏时删除 venv 目录重跑 `install-complete.bat` / `start-services.*`。

### 数据库问题
- 数据库文件：`backend/yunwei_docs.db`（SQLite）。
- 如需重置：**先备份**再删除该文件（会丢失全部数据）。

## 生产环境部署建议

开发脚本适合内网直接跑；对外提供服务时建议：
1. 用进程管理器托管后端（systemd / PM2 / NSSM），替代 `start-services.*` 的手动窗口
2. Nginx 反向代理 + SSL（示例见 [部署指南.md](部署指南.md)）
3. **不要**把 8002 端口直接暴露公网——MCP 端点与部分管理接口不依赖 token 鉴权
4. 配置日志轮转（`logs/`）、定期备份 `backend/yunwei_docs.db` 与 `backend/uploads/`
